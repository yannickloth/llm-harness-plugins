# LaTeX Format Fix

Converts formatting to LaTeX and normalizes conventions. Delegates to `latex-formatting-fixer`.

Usage: `/latex-format <scope>`
- Scope: file path or glob. Required.

Agent: `latex-formatting-fixer` — converts Markdown to LaTeX, normalizes formatting conventions in .tex files.
